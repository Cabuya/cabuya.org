# Code of Conduct

The Cabuya Protocol adopts the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full, with two project-specific additions below.

The Covenant text is not restated here. Restating it produces a copy that drifts
from the canonical version and a reader who cannot tell which one binds — the
link is the text, and it is the same text this project would have written.

## Addition 1 — reporting goes to a role, never to a person

Reports go to a **project alias monitored by at least two maintainers
representing two different applications**, published in
[`MAINTAINERS.md`](MAINTAINERS.md) alongside the current holders.

Not to a named individual, and this is the reason: in a project where one
organisation wrote the first draft, sending reports to an individual means that
reporting a maintainer can require reporting them to themselves. A role alias
with holders from two different applications removes that, and the composition
requirement is what makes the alias worth anything.

While the council is not yet seated, reports go through a **private security
advisory** on the repository, which is visible only to repository
administrators. That is stated plainly rather than advertising an alias nobody
is monitoring yet.

## Addition 2 — recusal

A maintainer who is the subject of a report **takes no part in handling it** —
not in the discussion, not in the decision, not in reading the report.

If the alias-holders are themselves conflicted, the remaining maintainers
appoint a temporary handler. If there are no unconflicted maintainers, the
report is handled by a person the reporter agrees to, and that fact is recorded
in the outcome.

## What happens to a report

The Covenant's enforcement ladder — correction, warning, temporary ban,
permanent ban — applies as written. Two commitments about the process itself:

- **A report is acknowledged within 48 hours**, even when the answer is only
  that it has been received and by whom.
- **Outcomes involving a maintainer are recorded publicly with a reason**, as
  [`GOVERNANCE.md`](GOVERNANCE.md#emeritus-and-removal) requires for removal.
  The details of a report are not public; the fact that action was taken, and
  why, is.

## Scope

The Covenant's scope applies: project spaces, and public spaces where someone is
representing the project.

One clarification, because this project's contributors mostly meet each other
somewhere else: **conduct in another community is not within scope here**, and
conduct in this one is not excused by having occurred in a shared channel that
also serves another project. If something happened in a space this project does
not run, we cannot act on it as a project — but nothing prevents us acting on
behaviour that continues here.
