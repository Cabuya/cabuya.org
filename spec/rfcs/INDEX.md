# RFC index

Normative changes to the Cabuya Protocol land only through this process.
Start from [`0000-template.md`](./0000-template.md); numbers are assigned in
PR order and never reused.

| RFC | Title | Tier | Status | Opened | Decided |
|---|---|---|---|---|---|
| [0001](./0001-founding-agreement.md) | Founding agreement · Acuerdo fundacional | governance | **draft — open for signature** | 2026-08-16 | — |
| [0002](./0002-v02-entities-and-coverage.md) | v0.2 entities and coverage · Entidades y cobertura v0.2 | normative | **draft — open for review** | 2026-08-19 | — |

Process rules (from the governance model): affirmative explicit agreement for
governance-tier RFCs; lazy consensus with a published window for normative
ones; the Privacy & PII review can decline an RFC on its own; an RFC with no
reference implementation is reviewable but not acceptable.
