# docs/visuals — the illustration pack

Wordless generated artwork for cabuya.org. Anything with text is a diagram
component instead: `docs/DIAGRAM_COMPONENTS.md`.

| File | What it is |
|---|---|
| [STYLE_GUIDE.md](./STYLE_GUIDE.md) | The house style block, palette, edges rule, dimensions, and the prompt entry schema. Read first |
| [VISUAL_INVENTORY.md](./VISUAL_INVENTORY.md) | Every surface on the site, classified illustration / diagram / skip |
| [INTEGRATION_GUIDE.md](./INTEGRATION_GUIDE.md) | What to do with a generated file: accept checks, conversion, embedding, the placeholder policy |
| `prompts/01-homepage.md` | Hero (flagship) and the join piece |
| `prompts/02-developers.md` | Portal, quickstart, validator, skill |
| `prompts/03-registry-governance.md` | Registry net, governance hands, join splice |
| `prompts/04-og-images.md` | The share card, and why per-section cards are deferred |
| `prompts/05-icons-ornaments.md` | 404, empty state, section ornament |

**Thirteen illustrations, ten skip decisions.** Each **Prompt** field is
self-contained: hand it to an image agent with no other context and the result
should be usable.

A mirror of this pack lives at
`.dwp/plans/PLAN_cabuya_website_and_skill/analysis_results/illustrations/`,
where the migration plan's deliverables are collected. `docs/visuals/` is the
permanent home; the mirror is a snapshot.
