## What the code covers

Corag coordinates aid between people who are frequently having a bad time. The
code treats how we behave as part of the service rather than as a side note, and
it applies to every Corag space — conversations inside operational fronts,
public channels, in-person events, code repositories, and any interaction where
someone acts on Corag's behalf.

Its most important rule, and the one most likely to be broken with good
intentions, is that **other people's personal data is not published without
their explicit authorization** — phone numbers, addresses, exact locations,
identifiable photographs. "It was urgent" is not an exception.

## For contributors to this repository

- The code applies to issues, pull requests and reviews.
- Reports go through the conduct form on `/conduct`, which accepts anonymous
  submissions. An anonymous report stores neither name nor email, even if the
  browser sends them — see `functions/api/contact.ts`.
- If anyone is in immediate danger, contact local emergency services first.
  This channel is not an emergency service.
